# Mimi Wallpapers

[English](README.md) · **Русский** · [Español](README.es.md)

Живые обои на рабочий стол с **Mimi**, персонажем из анимаций **[Typh](https://www.youtube.com/@crispytyph)**.
Бесплатный некоммерческий фан-проект **MimiFanStudio**.

> **Изображения Mimi и встроенный ролик используются с разрешения Typh.** Mimi и все анимации © Typh.
> Программа скачивает ролики с официального YouTube-канала Typh к вам на компьютер **только для личных обоев**.
> Поддерживайте автора: смотрите и лайкайте его ролики на YouTube.

## Возможности
- **Каталог анимаций Typh**: названия и превью берутся прямо с YouTube.
- **Только канал Typh**: новые ролики можно добавлять по ссылке, но только с канала Typh. Программа проверяет ID канала.
- **Скачивание в лучшем качестве**: до 4K 60 к/с со звуком, через [yt-dlp](https://github.com/yt-dlp/yt-dlp). Полоса загрузки никогда не едет назад.
- **Без длинных титров**: титры в конце ролика отрезаются автоматически после скачивания, без потери качества.
- **Свой движок обоев**: ролик одной кнопкой встаёт на рабочий стол под ярлыки и крутится по кругу, с аппаратным декодированием (внутри [mpv](https://mpv.io)). Lively Wallpaper и другие программы для обоев не нужны.
  - обои на каждом мониторе;
  - пауза, пока открыта полноэкранная игра или видео: видеокарта не тратится зря;
  - ролики меняются без мелькания, обои возвращаются сами после перезапуска Проводника.
- **Экран блокировки**: выбираете кадр ползунком, он ставится в полном разрешении без прав администратора.
- **Звук вкл/выкл** и громкость обоев. По умолчанию звук играет только на рабочем столе без окон; включите в Настройках **«Звук везде»**, чтобы слышать его в любом окне и вкладке.
- **Запуск с Windows**: после перезагрузки возвращаются последние обои.
- **Языки**: русский, английский, испанский.
- **Установщик с Mimi**: с первой секунды крутится анимированный фон с Mimi, есть условия использования. Первые обои (KISS ME) уже внутри установщика: работают сразу, даже без VPN. Ставит программу в папку пользователя (без прав администратора), недостающие программы берёт из `winget`. Удаляется через «Программы и компоненты».

## Установка
1. Скачайте `MimiWallpapers_Setup_public.exe` в разделе [Releases](../../releases).
2. Запустите, выберите язык, примите условия и нажмите **Установить**.
   Если нужно, установщик сам поставит mpv, yt-dlp и FFmpeg из официального каталога Windows `winget`.
3. Откройте **Mimi Wallpapers**, выберите ролик, затем **Скачать** → **Поставить на обои**.

Нужно: Windows 10/11 x64 и интернет.

> ⚠️ **Видео скачиваются с YouTube.** Если в вашей стране YouTube заблокирован или замедлен, обои **не скачаются без VPN** (или другого способа открыть YouTube). Уже скачанные обои работают и без интернета.

## Сборка из исходников
```powershell
python -m venv .venv
.venv\Scripts\pip install PySide6-Essentials pyinstaller pywinauto pillow
powershell -ExecutionPolicy Bypass -File build.ps1 -Public
```
Готовый установщик появится в `installer\MimiWallpapers_Setup_public.exe`.

Оформление с Mimi (`launcher_bg.mp4`, `setup_bg.webp`, `mimi.ico`, `mimi.png`) лежит в репозитории и используется с разрешения Typh. Первый ролик каталога вшивается в установщик, если он уже скачан в `%LOCALAPPDATA%\MimiWallpapers\videos`.

## Устройство проекта
| Путь | Что это |
|---|---|
| `launcher/mimi_launcher.py` | лаунчер (Python + PySide6) |
| `launcher/engine.py` | движок обоев (работает в фоне как `MimiWallpapers.exe --engine`) |
| `launcher/setup.py` | установщик |
| `launcher/common.py` | общие пути, стиль, анимированный фон |
| `launcher/i18n.py` | переводы, условия использования, ID канала Typh |
| `catalog.json` | каталог роликов (ID на YouTube и названия) |
| `launcher_bg.mp4`, `setup_bg.webp`, `mimi.ico`, `mimi.png` | оформление с Mimi (с разрешения Typh) |
| `docs/` | скриншоты |
| `tools/make_public_assets.py` | создаёт запасную графику при сборке |
| `tests/` | UI-тесты (pywinauto): лаунчер, установка, удаление |
| `build.ps1` | сборка |
